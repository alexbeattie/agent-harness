Install the shared workflows in Cursor, Codex CLI, Claude Code, or all three on Windows 11.

Start with [the Windows quick start](docs/WINDOWS-QUICK-START.md). The default installer prepares all three; `-Agents cursor`, `-Agents codex` and `-Agents claude` select an individual setup.

Codex CLI and Claude Code run from any PowerShell terminal, including terminals in other editors. Each has its own configured launch command and skill instructions. Cursor uses its own agent chat.

AWS and TWG wrappers are included; installing and checking those services is optional.

[The document index](docs/README.md) links the configuration, maintenance and Windows acceptance guides. Native Windows acceptance remains pending.
