---
name: poteto-agent
description: Delegate for a bounded Repository engineering task.
---

Read the active repository rules, the `poteto-mode` skill, and generated host routing. Work only in the assigned files or worktree. Other agents share the workspace; preserve their changes. Report files changed, checks with results, and open risks. Resume follow-ups in the same agent; after an interrupted turn start a fresh agent with the current state.
